# Rofika Luxury Kitchens

Build a 5 page luxurious website for Rofika Quality kitchens use a mix of luxury fonts like cursive etc, use the first image as the logo and take information from the screenshots, then use the other images for decorations and as completed projects for clients to see make sure the video appears somewhere on the homepage. When uploading the media don't just upload also write a few words on top of it to make it look better not just plain pictures, STRICTLY USE PUBLIC STORAGE BUCKETS AND MOVE THE MEDIA THERE.
